# Homebrew tap for AZpdf

[AZpdf](https://github.com/h3nryprod01/AZpdf) — an open-source, local-first PDF
reader and editor for macOS.

```bash
brew tap h3nryprod01/azpdf
brew install --cask azpdf
```

Apple silicon (arm64), macOS 14 Sonoma or later. The app is signed with a
Developer ID and notarized by Apple, so it opens without a Gatekeeper warning.
